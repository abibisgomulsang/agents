# 📦 상품 상세 데이터 입력 양식 (Product Data Input Form)

각 상품별로 아래 항목을 구체적인 수치와 설명을 기입해 주십시오.

## 1. 기본 정보 (Identification)
| 항목 | 입력 내용 | 비고 |
| :--- | :--- | :--- |
| **상품명** | [예: 프리미엄 캣타워 세트] | |
| **제품 유형** | [예: 장난감, 용품, 구독 서비스 등] | |
| **포지셔닝 레벨** | [코어 / 프리미엄 / 경험] (선택 필수) | 수익화 모델 결정의 핵심 기준 |

## 2. 재무 및 원가 데이터 (Financial & Cost Data)
| 항목 | 입력 내용 | 단위 |
| :--- | :--- | :--- |
| **원재료/제조 원가 (COGS)** | [실제 제작에 들어간 모든 비용] | 원 |
| **운영 비용 (직접비)** | [마케팅, 포장 등 직접 관련 운영 비용] | 원 |
| **총 생산 원가 (Total Cost)** | (원재료/제조 원가 + 운영 비용) | 원 |
| **현재 재고 수량** | [현재 보유하고 있는 수량] | 개 |

## 3. 시장 및 고객 반응 데이터 (Market & Customer Reaction)
| 항목 | 입력 내용 | 비고 |
| :--- | :--- | :--- |
| **경쟁사 평균 가격대** | [주요 경쟁 상품의 평균 판매가 범위] | 원 |
| **현재 판매 가격 (MSRP)** | [현재 자사몰에 책정된 판매 가격] | 원 |
| **고객 반응 지표 (Reaction Score)** | [실제 고객 리뷰, 댓글 등을 기반으로 산출한 정량적 점수 또는 의견 요약] | 1~10점 또는 텍스트 요약 |
| **차별화 포인트** | [이 상품만의 독보적인 가치 (감성, 기능, 소재 등)] | 핵심 키워드 |

---

### 📝 입력 예시 (Example Input)

**[예시] 프리미엄 캣타워 세트**

1.  **기본 정보:**
    *   상품명: 프리미엄 캣타워 세트
    *   제품 유형: 용품
    *   포지셔닝 레벨: **프리미엄** (선택)
2.  **재무 및 원가 데이터:**
    *   원재료/제조 원가 (COGS): 15,000원
    *   운영 비용 (직접비): 2,000원
    *   총 생산 원가 (Total Cost): 17,000원
    *   현재 재고 수량: 50개
3.  **시장 및 고객 반응 데이터:**
    *   경쟁사 평균 가격대: 35,000원 ~ 45,000원
    *   현재 판매 가격 (MSRP): 39,900원
    *   고객 반응 지표 (Reaction Score): 8.5점 (디자인 만족도 높음)
    *   차별화 포인트: 친환경 목재 사용, 수직 공간 활용 디자인
