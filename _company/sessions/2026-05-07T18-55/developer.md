## 🛠️ MVP 로드맵 검토 및 구현 우선순위 계획

CEO 지시에 따라, 기존 MVP 기술 로드맵(`sessions/2026-05-07T17-17/developer.md`)을 기반으로 상품 데이터 수신 시점의 효율적인 기능 구현 순서와 API 연동 계획을 수립합니다. 현재는 실제 상품 데이터가 없으므로, **데이터 유입에 따라 즉시 실행 가능한** 우선순위 프레임워크를 설계하는 데 집중합니다.

### 1. 핵심 기능 모듈 정의 (Module Definition)

로드맵상의 기능을 데이터 의존성 및 복잡도에 따라 세 가지 주요 모듈로 분류하고, 각 모듈의 API 연동 필요성을 명시합니다.

| 모듈 ID | 모듈 명 | 주요 기능 범위 | 데이터 의존성 | 예상 구현 복잡도 (T-Shirt Size) |
| :--- | :--- | :--- | :--- | :--- |
| **M1** | Reward System Core | 포인트 적립, 교환 로직, 사용자 리워드 상태 관리 | Business API (Reward Gold 매핑) | M |
| **M2** | Cat Warmth Hub | 상품 상세 목록 표시, 카테고리 필터링, 상품 상세 보기 | Business API (상품 데이터) | L |
| **M3** | User & Wallet | 사용자 인증/인가, Reward Gold 잔액 관리, 거래 기록 | M1 및 외부 인증 서비스 | M |

### 2. 구현 우선순위 결정 (Implementation Priority)

데이터 수신 즉시 최대의 가치를 제공하기 위해 다음과 같은 순서로 개발을 진행합니다. 이는 **최소 기능 제품(MVP)** 목표를 달성하는 데 초점을 맞춥니다.

**우선순위:** M3 → M1 → M2

#### A. 🥇 1순위: User & Wallet (M3) - 기반 환경 구축
*   **목표:** 시스템의 가장 기본적인 보안 및 사용자 상태 관리를 확립합니다.
*   **필수 작업:** 사용자 인증(로그인/회원가입), Reward Gold 잔액 CRUD 기능 구현, 거래 기록 로깅 API 설계.
*   **이유:** 다른 모든 기능은 이 모듈에 의존하므로, 데이터 수신 전이라도 시스템의 안전한 프레임을 구축해야 합니다.

#### B. 🥈 2순위: Reward System Core (M1) - 핵심 수익화 엔진
*   **목표:** 보상 및 리워드 시스템의 핵심 로직을 완성합니다.
*   **필수 작업:** Reward Gold 포인트의 적립/차감 로직 구현, 사용자 행동에 따른 리워드 발급 알고리즘(행동 경제학 기반) 통합.
*   **이유:** 수익화 모델의 핵심인 '보상' 메커니즘을 완성해야 데이터가 들어왔을 때 즉시 작동하는 엔진을 만들 수 있습니다.

#### C. 🥉 3순위: Cat Warmth Hub (M2) - 사용자 경험(UX) 구현
*   **목표:** 사용자가 실제로 상품을 탐색하고 구매를 유도하는 인터페이스를 구축합니다.
*   **필수 작업:** 상품 데이터 연동 API 설계, 목록 표시 UI/UX 구현, 필터링 및 검색 기능 통합.
*   **이유:** 상품 데이터가 도착하면 즉시 콘텐츠를 채워 넣을 수 있도록, 프론트엔드 연결에 필요한 백엔드 구조(API 스키마)를 미리 정의해 둡니다.

### 3. API 연동 계획 (API Integration Plan)

상품 데이터 수신 시점($T_{data}$)에 맞춰 외부 시스템과의 안정적인 통신을 보장하기 위한 API 엔드포인트 및 데이터 흐름을 정의합니다.

| API EndPoint | 목적 | 요청 데이터 (Input) | 응답 데이터 (Output) | 연동 대상 | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `/api/rewards/balance` | 사용자 잔액 조회 | User ID | Reward Gold 잔액, 거래 내역 요약 | M3 (Wallet) | 실시간 상태 제공 |
| `/api/products/list` | 상품 목록 조회 | Category, Sort Order | 상품 카드 리스트 (상품명, 썸네일, 가격) | M2 (Hub) | **$T_{data}$ 시점 필수 연동** |
| `/api/products/{id}` | 단일 상품 상세 조회 | Product ID | 상품 상세 정보 (상세 설명, 원가, 재고 등) | M2 (Hub) | **$T_{data}$ 시점 필수 연동** |
| `/api/rewards/claim` | 리워드 교환 요청 | Reward Gold ID, Item ID | 거래 성공 여부, 새로운 잔액 | M1 (Reward) | 핵심 트랜잭션 API |
