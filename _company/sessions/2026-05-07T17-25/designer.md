## 🖼️ Cat Warmth Hub (고양이 연결 및 상태 대시보드) - 레이아웃 초안

이 레이아웃은 감성적 연결 상태를 즉각적으로 인지하고, 사용자가 활동 기록에 쉽게 접근할 수 있도록 설계되었습니다.

### Screen 1: Warm Dashboard (핵심 대시보드)

*   **전체 배경:** `Cat Warmth` 색상 계열의 부드러운 그라데이션 (Warm & Cozy 느낌 강조).
*   **컬러 사용:** 주 기능(Primary Action)은 `Abibi Blue`, 보상/중요 지표는 `Reward Gold`.

| 영역 | 컴포넌트 | 상세 레이아웃 및 디자인 요소 | 비고 |
| :--- | :--- | :--- | :--- |
| **A. 상단 헤더** | 네비게이션 바 | 좌측: 로고/앱 이름 (Font: Bold, Abibi Blue). 우측: 알림 아이콘, 설정 아이콘. | 일관성 유지 |
| **B. 핵심 지표** | Cat Warmth Meter | 화면 중앙에 가장 크게 배치. 원형 게이지 형태. 현재 값(예: 75%)이 `Reward Gold` 색상으로 채워짐. | 감성적 연결의 시각화 |
| **C. 상태 요약 카드 (Card 1)** | Recent Interaction Feed | 중간 영역에 위치. 최근 상호작용 기록 목록 (최근 3건). 각 항목은 작은 아이콘과 시간 표시. | 데이터 기반 친근함 |
| **D. 행동 추천** | Status Snapshot | 하단 중앙에 배치. 현재 상태 요약 메시지 ("오늘의 목표: 쓰다듬기 완료! 다음 목표: 간식 제공"). CTA 버튼(`Next Action` - Reward System으로 이동). | 동기 부여 촉진 |

### Screen 2: Activity Log (활동 기록 상세)

*   **전체 배경:** `Abibi Blue` 계열의 깨끗하고 데이터 중심적인 배경.
*   **레이아웃:** 리스트 기반의 깔끔한 정보 전달에 집중합니다.

| 영역 | 컴포넌트 | 상세 레이아웃 및 디자인 요소 | 비고 |
| :--- | :--- | :--- | :--- |
| **A. 상단 필터** | Filter Bar | 화면 상단에 배치. 날짜 선택기, 활동 유형(쓰다듬기, 간식 등) 토글 버튼. | 데이터 검색 용이성 확보 |
| **B. 기록 리스트** | Activity List | 스크롤 가능한 메인 영역. 각 행은 시간(오른쪽 정렬), 활동 유형(왼쪽 강조), 보상 상태(아이콘). | 직관적인 히스토리 제공 |
| **C. 상세 모달** | Detail Modal | 특정 기록 클릭 시 팝업 또는 전체 화면 모달로 표시. 당시의 감정 상태 데이터(기록된 지표)를 차트 형태로 함께 표시. | 데이터 기반 깊이 제공 |

## 🎁 Reward System (보상 및 구독 관리) - 레이아웃 초안

이 레이아웃은 사용자가 목표 달성 과정에 몰입하고 보상을 받을 때 시각적 만족감을 극대화하도록 설계되었습니다.

### Screen 1: Reward Hub (보상 대시보드)

*   **전체 배경:** `Reward Gold`를 포인트 강조 색상으로 사용하여 성취감을 극대화합니다.
*   **레이아웃:** 상단에 현재 상태를 명확히 제시하고, 중앙에 목표 달성 현황을 시각적으로 보여줍니다.

| 영역 | 컴포넌트 | 상세 레이아웃 및 디자인 요소 | 비고 |
| :--- | :--- | :--- | :--- |
| **A. 총점 표시** | Total Points Display | 화면 최상단 중앙에 배치. 숫자(`1500`)를 가장 크고 굵게 표시하고, 배경은 은은한 `Reward Gold` 톤으로 처리. | 시각적 동기 부여의 핵심 |
| **B. 목표 추적 영역** | Goal Tracker | 화면 중앙에 배치. 현재 활성화된 구독 또는 행동 목표 (예: '주간 목표 달성률 60%'). 진행률은 막대 그래프 형태로 표시되며, 목표 달성 시 `Reward Gold`로 채워짐. | 목표 지향적 관리 |
| **C. 보상 목록** | Earned Rewards | 하단에 배치. 현재까지 획득한 리워드 아이템 목록 (뱃지 또는 장난감 이미지). 사용자가 획득 가능한 다음 보상을 명확히 제시하는 CTA 버튼. | 성취감 시각화 |
